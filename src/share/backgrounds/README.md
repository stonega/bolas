# Mesh shader backgrounds

The four original static PNG assets were authored with the
[Paper Design Mesh Gradient](https://shaders.paper.design/mesh-gradient)
generator and exported at a frozen animation frame. Bolas has no runtime
dependency on the website or its React package.

These four assets use `speed=0` and were exported at 1600 × 900. The source parameters
are retained below so each image can be regenerated intentionally.

| Asset | Colors | Distortion | Swirl | Grain mixer / overlay | Scale | Rotation | Offset |
|---|---|---:|---:|---:|---:|---:|---:|

| `ember-mesh.png` | `#ffe29a`, `#ff7a59`, `#c239b3`, `#3f1b70` | 0.91 | 0.58 | 0.12 / 0.09 | 1.18 | 205° | -0.06, 0.08 |
